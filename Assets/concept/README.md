# Концепты

**Главный герой — пилот** (концепт из другой, замороженной игры автора):
киберпанк-самурай в чёрном худи и тактическом жилете, хакама, катана,
светящиеся зелёные татуировки на руках, неоновые кроссовки; надписи 武士道
(«путь воина»).

- `hero_key_art.png` — ключевой арт (ночной неоновый город, дождь);
- `hero_turnaround.png` — разворот: спереди, сбоку, сзади.

Идеи использования: портрет пилота в меню и ангаре, диалоги перед уровнями
(брифинги альянса сопротивления), зелёный неон как акцентный цвет корабля
игрока и интерфейса.
