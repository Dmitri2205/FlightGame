# FlightGame

Вертикальный скролл-шутер в духе Sky Force: автострельба, звёзды-валюта,
прокачка корабля между вылетами. Движок — **Godot 4.3+** (GDScript),
портретная ориентация 720×1280.

## Запуск

1. Установить [Godot 4.3+](https://godotengine.org/download).
2. Открыть `project.godot` через менеджер проектов.
3. F5. На ПК корабль двигается перетаскиванием мышью или стрелками.

## Играть в браузере (в т.ч. с телефона)

При каждом пуше GitHub Actions (`.github/workflows/pages.yml`) прогоняет сцены
headless на ошибки скриптов, собирает веб-версию и выкладывает её на
GitHub Pages: **https://dmitri2205.github.io/FlightGame/**

Один раз нужно включить: *Settings → Pages → Build and deployment →
Source: GitHub Actions*.

### Отладка

- «Тест: сразу к боссу» в главном меню пропускает волны.
- Из командной строки: `godot --path . res://scenes/game/level.tscn -- --boss`.

## Структура

```
project.godot              настройки: экран, слои коллизий, autoload
scripts/game_state.gd      autoload GameState: звёзды, корабли, улучшения, баланс, сохранение
scripts/ship_data.gd       Resource ShipData — характеристики корабля
ships/*.tres               корабли: falcon (Сокол), swift (Стриж), bastion (Бастион)
ui/theme.tres              общая тема интерфейса
scenes/ui/
  main_menu.tscn/.gd       главное меню
  upgrade_menu.tscn/.gd    ангар (прокачка), строки строятся из GameState.UPGRADES
  ship_select.tscn/.gd     выбор и покупка кораблей
  hud.tscn/.gd             очки, здоровье, прогресс уровня, экран итогов
scenes/game/
  level.tscn/.gd           уровень: волны врагов, счёт, конец уровня
  player.tscn/.gd          корабль игрока
  enemy.gd                 общий скрипт врага
  enemy_fighter.tscn       лёгкий истребитель (виляет)
  enemy_gunship.tscn       тяжёлый, стреляет в игрока
  boss.tscn/.gd            босс в конце уровня (2 фазы: обычная и ярость с 50% HP)
  bullet.gd                общий скрипт пули
  player_bullet.tscn / enemy_bullet.tscn
  star_pickup.tscn/.gd     звезда, притягивается магнитом
  background.gd            временный процедурный фон
```

### Слои коллизий

| Слой | Кто | Кого ищет (mask) |
|---|---|---|
| 1 player | Игрок | — |
| 2 enemies | Враги | игрок (таран) |
| 3 player_bullets | Пули игрока | враги |
| 4 enemy_bullets | Пули врагов | игрок |
| 5 pickups | Звёзды | игрок |

### Корабли и инерция

Палец двигает «цель», а корабль догоняет её с инерцией: желаемая скорость
пропорциональна расстоянию до цели (`follow_gain`) и ограничена `max_speed`,
а менять скорость корабль может не быстрее, чем `thrust / mass`. Поэтому
тяжёлый Бастион заметно отстаёт от пальца и проскакивает точку остановки,
а лёгкий Стриж слушается почти мгновенно.

Новый корабль = новый `.tres` в `ships/` (можно создать в редакторе:
ПКМ → New Resource → ShipData) + путь в `GameState.SHIP_PATHS`.

### Баланс

Все формулы характеристик (здоровье, скорострельность, урон, радиус магнита)
и цены улучшений лежат в `scripts/game_state.gd`. Новое улучшение = новая
запись в `UPGRADES` + формула, которую читает `player.gd`.
