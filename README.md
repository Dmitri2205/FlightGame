# FlightGame

Вертикальный скролл-шутер в духе Sky Force: автострельба, звёзды-валюта,
прокачка корабля между вылетами. Движок — **Godot 4.3+** (GDScript),
портретная ориентация 720×1280.

## Запуск

1. Установить [Godot 4.3+](https://godotengine.org/download).
2. Открыть `project.godot` через менеджер проектов.
3. F5. На ПК корабль двигается перетаскиванием мышью или стрелками.

## Играть в браузере (в т.ч. с телефона)

Веб-версия: **https://dmitri2205.github.io/FlightGame/**

GitHub Actions (`.github/workflows/pages.yml`):

- **push в `main`** — сборка, smoke test (сцены headless на ошибки скриптов)
  и публикация на GitHub Pages;
- **pull request** — только сборка и smoke test, без публикации.

Порядок работы: изменения делаются в отдельной ветке → pull request в `main`
(CI должен быть зелёным) → слияние → игра обновляется на сайте.

Один раз в настройках репозитория: *Settings → Pages → Source: GitHub
Actions*, ветка по умолчанию — `main` (*Settings → General → Default branch*).

### Отладка

В главном меню — блок «Разработчику +». Игроку он не виден: в собранной
игре (в т.ч. на сайте) блок появляется после **7 быстрых тапов по названию**
игры (так же выключается, запоминается в сохранении); в отладочной сборке
из редактора виден всегда.

- «Превью волн» — пути траекторий и таймлайны уровней без боя;
- «Тест: все волны» — все волны из `data/waves` по порядку;
- «Тест: босс» — пропускает волны;
- «Сбросить прогресс» — в два нажатия.
- Из командной строки: `godot --path . res://scenes/game/level.tscn -- --boss`
  (или `-- --patterns`, `-- --level=глава:уровень`, с нуля).

### Слои коллизий

| Слой | Кто | Кого ищет (mask) |
|---|---|---|
| 1 player | Игрок | — |
| 2 enemies | Враги | игрок (таран) |
| 3 player_bullets | Пули игрока | враги |
| 4 enemy_bullets | Пули врагов | игрок |
| 5 pickups | Звёзды | игрок |

### Главное меню

- Живой фон: поверхность планеты текущей главы, облака, свой корабль
  (летает и стреляет, его можно водить пальцем) и пролетающие волны
  врагов-призраков — тот же `WaveDirector` и `GhostFlock`, что в превью.
- «ИГРАТЬ» (пульсирует) → карта уровней; под кнопкой — следующий
  непройденный уровень.
- «Корабль» (с картинкой выбранного корабля) и «Ангар».
- Отладочные кнопки спрятаны в «Разработчику +» (виден после 7 тапов по названию).

Общий вид кнопок и панелей задаёт тема `ui/theme.tres` (скруглённые
полупрозрачные кнопки с золотой рамкой) — для всех экранов сразу.

### Главы и карта уровней

Каждая глава — отдельная планета со своим биомом: цвет земли и набор декора
(`decor_prefix`: `decor_` — Марс, `decor_ice_` — Криос, `decor_toxic_` — Токсида).
В главе 4 уровня, последний — с боссом.

| Глава | Планета | Враги | Босс |
|---|---|---|---|
| 1 | Марс-7 — красная пустыня | здоровье ×1.0 | 500 HP |
| 2 | Криос — ледяная планета | здоровье ×1.4 | 800 HP |
| 3 | Токсида — ядовитый мир | здоровье ×1.9 | 1200 HP |

Уровень (`LevelData`) задаёт длительность, таймлайн волн и наполнители (см.
«Волны и траектории»), множитель здоровья врагов, босса и бонус звёзд за
первое прохождение.

Открытие: уровень — после прохождения предыдущего, глава — после финала
прошлой главы. Прогресс и рекорды хранятся в сохранении.

«Играть» в меню открывает карту: стрелками листаются главы, уровень, который
ждёт прохождения, пульсирует. После уровня — «Дальше», «Ещё раз» или «Карта».

Новый уровень = ещё один `LevelData` в `.tres` главы; новая глава = новый
`.tres` в `chapters/` + путь в `GameState.CHAPTER_PATHS` (+ при желании свой
набор декора в `tools/render_topdown.py`, словарь `BIOMES`).

### Корабли и инерция

Палец двигает «цель», а корабль догоняет её с инерцией: желаемая скорость
пропорциональна расстоянию до цели (`follow_gain`) и ограничена `max_speed`,
а менять скорость корабль может не быстрее, чем `thrust / mass`. Поэтому
тяжёлый Бастион заметно отстаёт от пальца и проскакивает точку остановки,
а лёгкий Стриж слушается почти мгновенно.

Новый корабль = новый `.tres` в `ships/` (можно создать в редакторе:
ПКМ → New Resource → ShipData) + путь в `GameState.SHIP_PATHS`.

### Волны и траектории (модули)

Всё, из чего строятся уровни, — **данные** (ресурсы `.tres`), правятся в
инспекторе Godot; код при этом не меняется.

```
FlightPattern  data/patterns/*.tres   траектория: старт, курс, манёвры (FlightStep)
WaveData       data/waves/*.tres      волна: сцена врага, траектория, сколько, расстояние (px), зеркало
LevelData      внутри chapters/*.tres таймлайн (TimelineEntry: секунда → волна) + наполнители
ChapterData    chapters/*.tres        планета, биом, список уровней
```

| Манёвр (FlightStep) | Поля | Что делает |
|---|---|---|
| LINE | distance | лететь прямо |
| TURN | angle, radius | повернуть по дуге; 360° — мёртвая петля (+ — против часовой) |
| AIM | duration, turn_rate | доворачивать на игрока |
| HOVER | duration | почти зависнуть (постоять и пострелять) |

После последнего манёвра враг летит прямо, пока не уйдёт с экрана.

На поворотах корабль **закладывает крен**: силуэт сужается и перекашивается,
будто корабль завалился на бок (`PatternMotion.bank` / `apply_bank()`); у
игрока так же — нос не поворачивается, только крен и лёгкий наклон.

Враги «паровозика» идут на расстоянии `spacing` пикселей друг от друга;
интервал выпуска считается из скорости врага (`WaveData.spawn_interval()`),
поэтому зазор одинаковый для быстрых и медленных врагов.

Модули, которые это исполняют:

- `WaveDirector` (`scripts/wave_director.gd`) — расписание волн: таймлайн
  уровня + случайные наполнители с `filler_from` каждые `spawn_interval`.
  Ничего не знает про очки и HUD, только сообщает «выпусти врага»;
- `PatternMotion` (`scripts/pattern_motion.gd`) — движение по траектории;
  общее для врага в игре и для превью, поэтому превью точное;
- `level.gd` только собирает игрока, `WaveDirector`, HUD, счёт и босса;
- `Router` (autoload) — все переходы между экранами;
- `DataLibrary` — списки всех траекторий и волн.

**Превью волн** (меню → «Разработчику +», работает на телефоне):
«Траектории» — путь каждой траектории и её зеркала, манёвры, призраки на пути;
«Уровни» — таймлайн уровня и его проигрывание (×1/×2/×4) с путями волн.

Как собрать уровень (в редакторе Godot):

1. Нужна новая фигура — `data/patterns/`: ПКМ → New Resource → FlightPattern,
   добавить манёвры в `steps`.
2. Нужна новая волна — `data/waves/`: New Resource → WaveData (враг, траектория…).
3. Открыть главу `chapters/*.tres` → уровень → `timeline`: добавить
   TimelineEntry (секунда + волна); `filler_waves` — случайные волны после
   `filler_from`.
4. Посмотреть результат на экране «Превью волн».

CI проверяет данные (`tests/validate_data.gd`: ссылки на месте, таймлайн по
возрастанию и не длиннее уровня) и прогоняет каждый уровень каждой главы.

### Графика

Пак **Kenney Space Kit** (CC0, `Assets/kenney_space-kit.zip`, лицензия —
`art/LICENSE-kenney-space-kit.txt`) — это 3D-модели, а готовые картинки в нём
только сбоку и в изометрии. Поэтому спрайты «вид сверху» рендерятся из моделей
скриптом `tools/render_topdown.py` (numpy + Pillow, читает модели прямо из
архива):

```
python3 tools/render_topdown.py              # все спрайты
python3 tools/render_topdown.py ship_swift   # один
```

В скрипте (`SPRITES`) для каждого спрайта задаются модель, размер, поворот,
наклон камеры и перекраска деталей: корабли игрока — в свои цвета, враги —
в пурпурный, босс — в красный. Готовые PNG лежат в `art/sprites/` и
коммитятся, Godot импортирует их сам.

| Спрайт | Модель |
|---|---|
| Сокол / Стриж / Бастион | craft_speederA / craft_racer / craft_cargoA |
| Истребитель / тяжёлый / босс | craft_speederB / craft_miner / craft_cargoB |
| Декор поверхности | crater, craterLarge, rock*, rocks_small*, rock_crystals*, meteor |

### Визуальные эффекты

Пока без текстур — всё рисуется кодом и частицами (CPUParticles2D):

- `FX.explosion(pos, size)` — огонь, дым, обломки, вспышка + тряска;
  у врага размер задаётся `explosion_size`, у босса — серия взрывов;
- `FX.hit(pos)` — искры попадания пули;
- `FX.shake(сила, сек)` — тряска камеры (при попадании по игроку и взрывах);
- `Shadow` (scenes/fx/shadow.gd) — тень самолёта: копия силуэта со сдвигом
  «от солнца», чем меньше `shadow_scale`, тем выше самолёт;
- `EngineTrail` — след двигателя у игрока и истребителей;
- облака поверх поля боя летят быстрее земли — эффект глубины.

### Баланс

Все формулы характеристик (здоровье, скорострельность, урон, радиус магнита)
и цены улучшений лежат в `scripts/game_state.gd`. Новое улучшение = новая
запись в `UPGRADES` + формула, которую читает `player.gd`.
